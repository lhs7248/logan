# Web 复审缺陷修复与验收记录 · 2026-10-26

## 结论与边界

本轮按用户“修复不足、修复后继续 review”的授权，修复阅读连续性、关联调查、尝试结论、验证模式、人工进展、导入和解析定位、能力与同步提示。保留三项导航、六项调查工具、批量导入、Web 样例、解析历史、人工调查、回写与已有推送流程。不接真实 AI、阿里云或源码映射，不修改真实服务和业务数据，不自动提交。

**功能修复与自动验收不等于整站设计验收完成。** 浏览器已实际走通下表核心流程；最终版本的整页对照、断线恢复截图和逐页补拍，被浏览器保存的网站权限持续拒绝。用户两次明确允许/解除后仍收到同一权限拒绝；未改用其他浏览器或绕过权限。该项保留为未验证，不能称“整站已无问题”或“产品最终验收完成”。

最终 109 项前端测试、Go test/race/vet/build、工作台 Go 测试、人工调查/阅读/推送回调三组隔离 HTTP 验收均通过，期间源码指纹未变化。隔离预览更新到该验收程序后，私有配置与状态文件重启前后逐字节一致。最终自动验证结果见 [自动验收索引](evidence/web-review-fixes-2026-10-26/final-validation.json)；产品源码内容绑定见 [本轮源码指纹](evidence/web-review-fixes-2026-10-26/product-source.json)。临时运行端口、访问令牌和私有配置不进入本报告或截图。

## 修复后继续 review 发现的问题

1. **快速重复点击仍生成重复证据。** 首轮浏览器产生两个重复合成证据，定位为前一请求未完成时工作区尚未刷新。现按项目/身份/工单/批次/精确事件集合合并在途写入，已保存的同一集合复用。浏览器再对 mixed.jsonl 快速保存两次，仅新增一项；原有合成历史没有清理。
2. **假设字段仍被隐藏。** 原 DOM 帮助函数把 hidden=false 写成 HTML 字符串属性，实际仍隐藏。改用布尔属性，浏览器再次切换后可选择假设并成功保存；新增回归覆盖真假两种值。
3. **新表单继承旧弹窗滚动。** 重建弹窗后重置到标题，避免目的切换后标题和关联字段不在视口。自动回归通过，最终截图复验受权限阻挡。
4. **未解析文件无法通过页面地址恢复。** 增加 asset 导航身份，并重新核对资产仍在授权工作区。URL/历史回归通过；最终浏览器重载复验未完成。
5. **筛选外事件选择返回时被直接丢弃。** 阶段导航可合法打开筛选外事件，不能仅和已加载列表求交。恢复时单独重新读取授权上下文，并核对 runId；异步读取完成后原子发布，拒绝迟到或跨范围响应。自动回归覆盖隐藏错误事件、拒绝访问及其他批次事件。
6. **选择数量与证据上限不一致。** 按既有每份证据最多 100 条的契约，在勾选时即时提示，保留原选择；不再等提交才发现，也不在历史恢复时静默截断有效选择。

## 数据与修改范围
