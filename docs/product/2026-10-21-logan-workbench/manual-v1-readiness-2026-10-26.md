# 日志阅读与人工调查 V1：上线缺口及验收

日期：2026-10-26。目标为企业内网、单实例、本地磁盘、小规模使用。产品界面继续使用既有 [产品设计](product-design.md)；本次没有改导航、布局、SDK 或历史数据。实现基线为 a5754a38bd9711780dbb92b7d0c4801867b80490，本次 V1 提交包含运行保障代码、验收报告和运行手册。

## 结论

已补齐本地可以实现和自动验收的运行保障，形成内网单实例部署候选版本。日志阅读与人工调查可在未配置模型的情况下完成。实际内网部署的网关、备份保护和业务负载尚未验收，因此不能把这份本地报告当作生产上线放行。

AI、阿里云推送和源码映射继续暂缓；保留原有入口、历史内容和明确未配置状态。回写对象是平台内部工单的不可变更新记录，本次没有接外部工单系统。

## 缺口逐项处理

| 项目 | 实现或处理 | 验收结论 |
| --- | --- | --- |
| 项目/令牌配置有歧义 | 启动拒绝重复项目、重复令牌、未知项目授权和未知角色；保留 SDK 独立凭据检查 | 通过：Go 启动测试及真实 HTTP |
| 内网运行配置缺少约束 | 新增显式 manual-v1 配置档：私有且归当前用户的授权文件、绝对私有数据目录、拒绝符号链接路径、单实例文件存储；默认本机启动仍兼容 | 通过：有效配置启动，错误配置拒绝；不会默默修改原配置权限 |
| 服务存活与可用状态混淆 | 新增 /healthz 和 /readyz，持久化异常或关闭后 readiness 返回 503，只输出通用状态 | 通过：状态测试与现有服务两接口 200；没有修改旧兼容服务 readiness |
| 备份只有文字说明 | 新增离线备份、完整性校验、恢复工具；与服务共用排他锁；校验状态/授权结构与 SHA-256；私有权限与落盘同步 | 通过：持锁拒绝、损坏拒绝、路径攻击拒绝、已有输出拒绝、文件与目录同步 |
| 恢复可能覆盖旧数据 | 只允许恢复到不存在的新目录，保留全部业务对象、原始字节、幂等回执与授权；附加配置需显式选择 | 通过：合成数据恢复后重新认证及业务读取一致；已有实际本地备份恢复副本逐文件一致 |
| 失败解析与阅读连续性 | 保留严格失败版本，通过跳过坏行的新解析版本继续阅读，原文件不改写 | 通过：真实 HTTP 上传、原始字节核验、失败重解析、版本比较、空筛选及级别过滤 |
| 人工调查是否依赖 AI | 精确日志事件作为证据，独立记录人工观察、候选假设、支持/反驳/无法确定，再预览与确认回写 | 通过：无模型权限完成；假设验证不能替代修复验证；修复验证后才能按状态规则关闭 |
| 多项目和角色隔离 | 既检查无项目授权的 403，也用有其他项目授权的身份验证对象隔离 | 通过：异项目工单、原始文件、事件均 404，异项目资料库为空；viewer 无法写入及读取未授权原始文件 |
| 重启后丢记录或重复回写 | 保留既有持久化、版本和幂等控制；核对原始日志、解析事件、调查材料和内部工单更新 | 通过：正常重启、空闲时强制终止重启、备份恢复均一致；重复回写仍只保存一次 |
| 筛选分页和统计一致性 | 新增 2,000 条合成事件验收，137 条/页遍历，核对 200 条 ERROR 与直方图 filterHash | 通过：不重不漏；30 次串行筛选读取记录耗时，仅代表该本机样本 |
| 持久化故障与容量拒绝 | 复用已有故障注入和状态容量测试，验证失败不部分提交且停止后续操作 | 通过：完整 Go 测试；尚未执行物理磁盘写满或断电 |
| 既有产品与数据保留 | UI/SDK 源码不变；原本机运行服务升级后读取同一数据，保留 9 资产、9 解析、4 证据、1 验证、2 更新 | 通过：5 份已有配置/完整状态文件字节摘要不变，10 份其他未提交文件摘要不变；浏览器刷新后原调查可继续 |

## 使用与恢复

严格配置与备份恢复命令见 [运行手册](../../../Logan/ServerGo/docs/manual-v1-operations.md)。复跑合成端到端验收，从 ServerGo 目录执行：

```sh
go build -o /private/tmp/workbench-manual-v1 ./cmd/workbench
python3 script/verify-workbench-manual-v1.py --binary /private/tmp/workbench-manual-v1 --report /private/tmp/manual-v1-new-report.json
```

报告目标必须不存在。测试自动申请独立回环端口和临时目录。所有已有本地配置、原始日志和真实上传记录均不作为测试写入目标。

本次已在本机私有运行目录保留一份升级前离线备份与一份独立恢复演练副本，未将真实内容加入仓库。本地启动器继续沿用原配置；严格 manual-v1 档在隔离服务中已验证，部署时须按运行手册显式启用。现有本地工作台已重建并恢复启动，无配置轮换、无数据迁移。
