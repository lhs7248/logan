## 使用入口与结构

- 新入口：`/workbench/`，新接口：`/logan-web/api/workbench/v1`。
- [运行说明](../../../Logan/ServerGo/docs/workbench.md)：身份配置、持久化、可选连接及回滚。
- [客户端说明](../../../Logan/ServerGo/internal/workbenchui/README.md)：页面操作及浏览器验收路线。
- [连接器说明](../../../Logan/ServerGo/internal/workbench/connectors/README.md)：Git、模型、协议及旧任务适配。
- [执行计划](../../superpowers/plans/2026-10-21-workbench-v1-implementation.md)：路由和开发选择。

实现采用现有 Go 模块中的独立程序，并将无需前端依赖构建的 ES module 客户端嵌入二进制。旧服务可以继续运行；新程序不会启动时自动修改旧库。默认本地持久化提供单实例锁和原子保存；MySQL 适配须先显式执行独立迁移。当前选择便于先交付完整服务链路，不构成生产架构容量承诺。

## 验收事实与限制

[本轮验收记录](evidence/implementation-2026-10-21/README.md)包含最终完整回归结果、15 项真实 HTTP 验收、浏览器流程和截图。

自动测试使用隔离数据及临时 Git 仓库；HTTP 模型测试使用本机测试服务，仅证明请求、快照、引用、取消和权限处理，不证明诊断质量。旧接口回归与原型回归单独执行。

[固定 AI 调查样本](evaluations/investigation-cases.json)包含 20 个用例，标注可支持事实、未知项、禁止结论及允许引用。真实模型人工评审状态为 `not_run`，不能当成已通过 AI 质量验收。

没有真实阿里云、外部工单或真实模型的成功记录，也没有以测试替身证明生产数据库、容量或发布就绪。产品规格中的 AT 场景继续作为正式验收清单；其标记 S/I/R 的要求不能仅凭浏览器截图或测试替身替代。
